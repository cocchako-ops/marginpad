# MarginPad Calculators — Chrome Web Store (UPDATE v1.1.0)

This is an **update to the existing published extension** (redesigned popup, same 5 offline calculators).

## Files

- Store promo tile (1280×800): `store-promo-1280x800.png`
- Popup screenshot: `store-screenshot-popup.png`

## How to publish the update
1. Go to the **Chrome Web Store Developer Dashboard** → https://chrome.google.com/webstore/devconsole
2. Open the existing **"MarginPad — Crypto Liquidation & Position Size Calculator"** item.
3. Left menu → **Package** → **Upload new package** → choose `dist-marginpad-calculators-v1.1.0.zip`.
4. (Optional) Store listing → Screenshots → add `store-promo-1280x800.png` (1280×800 is an accepted size).
5. **Save draft** → **Submit for review**. Reviews usually take a few hours to a couple of days.

## What changed in 1.1.0
- Full visual redesign (quant-terminal look: mono numerals, lime accent, result cards with a live long/short color accent, smoother tabs).
- Liquidation & Take-Profit inputs regrouped into tidy two-column rows.
- Still 100% offline, no permissions, no tracking (description updated to say so).
